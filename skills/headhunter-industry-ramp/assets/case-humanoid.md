# 完整跑通示例：人形机器人赛道

> **这份文件只示范结构和判断方式，不是可直接交付的研究成果。**
> 文中涉及的公司信息为公开资料整理，具有时效性，实际使用时必须按 L1 来源（招股书、年报、官网公告）重新核验。
> 团队与人才部分刻意留了 `【待补】`——公开信息支撑不了的地方就留白，编造一个看起来合理的人名会污染后面所有判断。

## 场景

客户给的岗位：**人形机器人研发总监**。你此前没接触过这个赛道。

---

## 阶段 0 · 岗位锚定

JD 里出现的高频词：VLA、全身控制、强化学习、Sim2Real、灵巧手、量产交付、团队搭建。

| 维度 | JD 线索 | 推断 | 置信度 |
|---|---|---|---|
| 技术栈 | VLA + 强化学习 + 全身控制三项并列 | 客户自己路线未定，或想要"全能型"（大概率是前者） | ❓ 待确认 |
| 岗位性质 | "搭建团队""从 0 到 1" | 新建团队，组织扩张期，话语权大 | 🟡 |
| 阶段要求 | "有量产落地经验" | 公司已过样机阶段，进入交付压力期 | 🟡 |
| 汇报关系 | JD 未写 | 必问 | ❓ |
| 目标公司池（我的初猜） | 优必选、傅利叶、宇树、智元 + 大厂机器人部门 | 待阶段 3 验证 | ❓ |

**待确认 5 项**（首次客户沟通用）：新设还是补位、最不能妥协的一条、汇报给谁+团队现有人数、薪酬上限与期权、之前面过的人卡在哪。

> 观察：一个 JD 同时要三种技术路线的人，通常意味着这家公司的技术路线还在摇摆。这对猎头是好消息——路线未定的时候，能同时理解多条路线的人最贵。

## 阶段 1 · 术语表（节选）

| 术语 | 一句话解释 | 所属层 |
|---|---|---|
| 本体 | 机器人的机械结构整体，不含算法 | 中游 |
| 自由度(DoF) | 可独立运动的关节数量，决定动作能力上限 | 中游 |
| 谐波减速器 | 高精度小体积减速装置，关节核心件，成本占比高 | 上游 |
| 无框力矩电机 | 直接集成进关节的电机，省空间 | 上游 |
| 灵巧手 | 多指、可精细操作的末端执行器 | 中游 |
| 运动控制 | 让机器人稳定行走、保持平衡的控制算法 | 技术-控制 |
| WBC 全身控制 | 同时协调全身关节完成任务的算法框架 | 技术-控制 |
| MPC 模型预测控制 | 基于动力学模型预测未来状态并优化动作 | 技术-控制 |
| 强化学习(RL) | 通过试错与奖励信号训练策略 | 技术-算法 |
| Sim2Real | 在仿真中训练、迁移到真机，解决真机训练成本高 | 技术-算法 |
| 遥操作 | 人穿戴设备示范动作，采集训练数据 | 技术-数据 |
| VLA | 视觉-语言-动作模型，端到端把指令变成动作 | 技术-算法 |
| 具身智能 | 强调智能体通过身体与环境交互获得能力 | 概念 |
| 数据闭环 | 采集→训练→部署→回收数据的循环体系 | 技术-数据 |
| BOM 成本 | 物料清单成本，硬件公司的成本基本盘 | 商业 |

判断标准：**能不能用这 15 个词跟候选人对话而不露馅**。不能，回去补。

## 阶段 1 · 产业链分层

```
上游 · 核心零部件（毛利相对高，国产替代进行中）
  ├─ 减速器：谐波/RV —— 精密制造，壁垒高
  ├─ 电机：无框力矩电机、空心杯电机
  ├─ 丝杠：行星滚柱丝杠（线性关节关键件，国产化率低）
  ├─ 传感器：IMU、力/力矩、触觉
  └─ 芯片与算力模组

中游 · 本体与整机（当前竞争最激烈，多数不赚钱）
  ├─ 全尺寸人形（工业/商用场景）
  ├─ 中小型人形（科研/教育/开发者）
  └─ 灵巧手、关节模组（可独立对外供货的模块商）

下游 · 场景与集成
  ├─ 工业制造（车企产线、3C 装配）
  ├─ 商用服务（导览、巡检、零售）
  ├─ 特种与危险作业
  └─ 科研教育（当前最真实的出货来源之一）
```

**价值分布判断**：现阶段整机厂普遍亏损，真正稳定赚钱的是上游零部件和"卖铲子"的模组商。
对猎头的意义：上游公司（减速器、丝杠、电机）里有大量高价值人才，竞争却比整机厂小得多，价格也理性——这是被普遍忽略的池子。

## 阶段 1 · 技术路线对比

分三个维度看，不要笼统说"技术路线"：

| 维度 | 路线 A | 路线 B | 取舍 |
|---|---|---|---|
| 决策（大脑） | VLA 端到端：感知直接出动作 | 分层：大模型做任务规划 + 传统模块执行 | A 上限高但要海量数据；B 工程可控但难通用 |
| 控制（小脑） | 强化学习 + Sim2Real | 模型控制（MPC/WBC）+ 动力学建模 | A 泛化好但 sim2real gap 难；B 稳定但场景迁移成本高 |
| 数据 | 真机遥操作采集 | 仿真合成 + 视频学习 | 前者质量高成本高，后者便宜但真实性打折 |

**行业现状**：多数公司是混搭——分层规划 + RL 控制 + 遥操作数据。真正端到端跑通量产的还没有。
这就是为什么 JD 里三种词会同时出现：不是客户贪心，是行业内没人有标准答案。

## 阶段 3 · 四张公司卡

### 优必选（老牌）
- **产品**：Walker 系列全尺寸人形，主打工业与商用场景
- **技术**：伺服舵机自研起家，硬件与量产工程能力强于算法叙事
- **团队**：`【待补】` —— 从年报"研发人员数量"、官网团队页、招聘页面方向分布入手
- **商业化**：港股上市，信息透明度最高，是四家里唯一能用财报验证的（看营收构成与亏损结构）
- **最新动态**：以公告为准
- **对本岗位**：**人才来源**。硬件、伺服、量产工艺人才密度最高；算法侧相对弱，挖算法不必首选它

### 傅利叶（老牌）
- **产品**：康复机器人起家 → 通用人形 GR 系列
- **技术**：医疗级力控与安全性积累，是它做人形的底层优势
- **团队**：`【待补】`
- **商业化**：康复业务有真实收入，人形业务处于推广期
- **对本岗位**：**人才来源**。力控、执行器、医疗场景落地经验的人才稀缺，这类人不太好找替代

### 宇树（新锐）
- **产品**：四足起家，人形走性价比路线，价格显著低于同行
- **技术**：运动控制与硬件成本控制能力强，强在"便宜且能跑"
- **团队**：`【待补】`
- **商业化**：出货量在同类中靠前，客户结构以科研、开发者、海外为主
- **对本岗位**：**人才来源 + 潜在客户**。运动控制、关节模组人才的核心池

### 智元（新锐）
- **产品**：远征系列 + 灵犀系列，覆盖全尺寸与轻量
- **技术**：端到端与大模型路线倾向最明显，走开源与数据生态
- **团队**：`【待补】` —— 创始团队学术背景强，关键看算法团队的组织形态
- **商业化**：量产爬坡期，节奏快，组织变动也快
- **对本岗位**：**人才来源 + 潜在客户**。VLA、数据闭环方向的人才最集中

### 横向对照（做完四张卡才看得出来）

| | 硬件/量产 | 算法/大模型 | 商业化进度 |
|---|---|---|---|
| 优必选 | 强 | 中 | 最前 |
| 傅利叶 | 强（医疗级） | 中 | 中 |
| 宇树 | 强（成本控制） | 中 | 前 |
| 智元 | 中 | 强 | 中 |

**结论**：客户 JD 强调"研发总监 + 搭建团队 + 量产经验"，真正匹配的是**优必选、傅利叶这类硬件体系出身、又带过交付的人**，而不是纯算法出身。这一条判断直接改变了搜寻方向——如果只按 JD 字面的"VLA"去搜，会找到一堆算法专家，但都不是总监料。

## 阶段 4 · 人才来源池

### 高校与科研机构（博士与工程骨干的主要来源）
上海交大、浙大、哈工大、北理工、清华、中科大、上海大学、南方科大等机器人相关实验室。
`【待补】` 具体课题组、导师、每年毕业生流向，需按 L1 核实（论文、实验室官网、毕业生去向）。

### 公司池（分层）
- **第一层（人形本体）**：优必选、傅利叶、宇树、智元、达闼、星动纪元、银河通用等
- **第二层（跨界大厂，薪酬碾压）**：小米、小鹏、华为、比亚迪、宁德时代等机器人/具身部门
- **第三层（四足与工业机器人）**：云深处、埃斯顿、新时达等——运动控制人才的稳定来源
- **第四层（上游零部件）**：谐波减速器、丝杠、电机厂商——关节与执行器专家的隐藏池

跨界大厂这一层常被漏掉：钱多、平台大、候选人不太愿意动，但一旦愿意，竞争力极强。

## 阶段 5 · 开场示例

> "看到你们在 VLA 上投入挺大，但现在业界做真机数据闭环的成本还是下不来，你们是走遥操作采集还是仿真为主？"

一句话里包含了：路线判断（VLA）、行业共识痛点（数据成本）、两条具体路径（遥操作/仿真）。
候选人听到这句会立刻判断"这人不是群发的"。然后你就可以闭嘴听——他讲三分钟，你对行业的理解比读十份研报还具体。

---

## 这个案例最容易踩的五个坑

1. **把发布会当量产**。上过晚会、跳过舞、跑过马拉松，都不等于能进厂干活。看交付台数和具名客户。
2. **把融资额当团队规模**。融资 10 亿不等于 500 人，硬件公司的钱大量花在产线和物料上。
3. **漏掉上游零部件公司**。关节、丝杠、电机领域的人才密度高、竞争小、价格理性。
4. **漏掉跨界大厂**。小米、小鹏、华为这类公司薪资结构完全是另一个量级，不放进池子会低估难度。
5. **用互联网岗位逻辑找硬件人才**。硬件人才看的是产品能不能真造出来，不是期权和职级，话术要换。
