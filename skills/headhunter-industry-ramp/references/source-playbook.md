# 阶段 1 · 信息源手册：六问、研报、招股书、年报、搜一搜

四类信息源分工不同：AI 给框架，研报给格局，招股书给细节，年报给真实数据。**顺序不能乱**——先有框架再读细节，否则读不进去。

## 一、AI 结构化六问

直接把下面这段提示词复制给 AI（替换行业名）。核心是把"讲故事"约束成"填表格"。

```
你是一名产业研究员，我要在 2 小时内进入【XX 行业】。请严格按以下结构输出，
不要写成散文，不要写行业愿景，只给可核对的信息。

1. 产业链分层：上游/中游/下游各是什么，每层列 3-5 家代表企业，
   标出价值量占比最高的环节，并说明为什么
2. 核心产品：按形态/规格分类，给出价格带区间（有区间就给区间，没有写"待核"）
3. 核心技术：5-8 项关键技术，每项说明解决什么问题、当前成熟度
   （实验室 / 小批量 / 量产三档）
4. 技术路线分歧：行业内 2-3 条互相竞争或互斥的路线，
   说明各自代表企业、各自的取舍和天花板
5. 玩家梯队：龙头 / 新锐 / 跨界入局 / 上游隐形冠军，各 3-5 家，
   注明最新融资轮次与产品阶段（不确定写"待核"）
6. 趋势与不确定：未来 3 年最可能发生的 3 个变化，最大的 2 个不确定性

最后附一张术语表：文中出现的所有专业名词，每个用一句话解释。

规则：凡是涉及具体数字（融资额、出货量、团队人数、市场份额），
如果你不确定，一律标注"待核验"，绝对不要编造一个看起来合理的数字。
```

三个使用要点：

- **追问出处**：拿到初稿后逐条问"这条的出处是什么"。答不出来的就是幻觉，标 L4。
- **换模型交叉验证**：同一个问题喂两个不同的模型，两份答案里冲突的地方就是需要重点核实的点。
- **不追问行业愿景**：让 AI 讲趋势它会给你一堆正确但没用的废话。只追问事实与结构。

## 二、券商行业研报

**渠道**：东方财富网行业研报板块（首选，免费，覆盖全）；补充可用慧博投研、发现报告。

**怎么选**：1 份全景报告建立框架 + 2 份近半年到一年的专题报告掌握最新动态。不要读 10 份，同质化严重。

**只读四页**：
1. 产业链图谱页——最好用的一页，直接截图进知识地图
2. 公司对比表——技术路线、产品、财务横向对比
3. 市场规模测算——**看假设不看结论**。结论是 2030 年千亿市场，假设是"渗透率每年翻倍"，后者才是有用信息
4. 风险提示——往往是最真实的部分，写满了行业当下解决不了的问题

**警惕**：券商有立场，覆盖的公司多为合作方，描述会偏正面；市场规模测算普遍偏乐观。研报定级 L2。

## 三、招股说明书

**为什么值得读**：招股书要承担法律责任，是所有材料里最诚实的。而且会系统性地解释行业术语。

**只读两章**：
- **释义**——行业术语的官方定义。比自己猜、比 AI 解释都准。术语表的一半可以直接从这里抄。
- **业务与技术**——核心产品、技术先进性论述、竞争对手对比、客户集中度、产能与良率。

**额外必读**：**风险因素**章节。那里写着这家公司和这个行业真正解决不了的问题——这些就是你和候选人聊天时最好的话题。

**渠道**：上交所/深交所官网、港交所披露易、巨潮资讯。搜"公司名 + 招股说明书"通常能直接拿到 PDF。

## 四、上市公司年报

**渠道**：巨潮资讯网（A 股）、港交所披露易（港股）、SEC EDGAR（美股）。

**看五处**：
1. 主营构成——到底哪块业务在赚钱（常有"宣传的业务不赚钱，赚钱的业务不宣传"）
2. 研发投入金额与占营收比
3. 研发人员数量与占比
4. 在建产能与募投项目
5. 前五大客户

**一个有用的算法**：研发投入 ÷ 研发人数 = 人均研发成本。用这个数反推同行的团队规模和薪酬水平，比问客户准。

## 五、微信搜一搜公式

**检索式**：`【企业名】+【关键词】`

关键词固定这几个：创始人 / 技术路线 / 研发团队 / 商业化 / 融资 / 量产 / 招聘

**读什么**：
- 公司官方公众号的技术推文（能看出他们自认为强在哪）
- 创始人、CTO 的公开演讲全文（能看出底层技术战略，比新闻稿信息量大一个数量级）
- 行业媒体的深度稿（能看出外部质疑）

**怎么读**：不看标题看细节。找四样东西——交付数量、具名客户、良率、单价。
"即将量产"= 还没量产；"小批量交付"= 有产品没规模；"获得某车企定点"= 有一单但没放量。

## 六、来源分级标注格式

在报告和地图里统一用这个格式：

```
宇树 2025 年人形机器人出货量约 X 台 🟡L2（某券商研报，2026-03）
优必选 Walker 系列主要落地场景为工业与商用 ✅L1（2025 年报）
智元新一代产品预计 2027 年量产 ❓L4（AI 推断，待核验）
```

三个级别的处理差异：
- ✅ L1：直接写，不用解释
- 🟡🔵 L2-L3：必须带来源和时间，因为半年后就可能失效
- ❓ L4：单独进"待核验清单"，不进正文结论

## 七、信息源可信度排序（速查）

官方公告/招股书 > 年报 > 专利 > 券商研报 > 行业协会/白皮书 > 官方公众号 > 科技媒体 > 创始人访谈 > 论坛/脉脉 > AI 输出

注意：创始人访谈的可信度不一定高（有立场、有夸大），但**信息密度**很高，适合用来找线索，不适合用来定结论。
