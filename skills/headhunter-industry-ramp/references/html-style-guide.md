# 报告版式规范（HTML 主载体）

本文件定义《行业速研与人才地图》的视觉与结构标准。**这是既定版式，不得自创。**

- 主模板：`templates/report-template.html`（复制即用，只替换 `{{}}`，不改 `<style>`）
- docx 由同一份 HTML 转换而来，节序与结论完全一致

## 为什么固定版式

客户看的是判断力，不是设计。但版式不稳定会让每份报告都像不同人写的，专业性打对折。固定版式的真正作用有三个：

1. **信息分级一眼可辨**：来源等级四色标签，客户三秒知道哪句能引用、哪句要存疑。
2. **结论优先**：封面就放一句话结论 + 四个数字，客户不翻页也能拿到核心。
3. **可复用**：新赛道只换内容，不用重新想排版，4 小时能出稿。

## 设计令牌（不得修改）

```
--ink:#0B1F33    正文主色（深海军蓝）
--ink-2:#1E3A56  次级正文
--muted:#5C6F82  弱化说明
--line:#DCE3EA   分隔线
--bg:#F5F7FA     页面底色
--accent:#D4552B 强调橙（结论、判断、关键动作）
--blue:#1B4F72   小标题、术语
--green:#1E7A5A  L1 可信 / 高分
--amber:#9A6B00  L3 媒体 / 中分 / 警示
--red:#B03A2E    L4 待核验 / 低分 / 风险
```

字体：系统字体栈（`-apple-system, PingFang SC, Microsoft YaHei`），正文 15px / 行高 1.75。
不引入任何外部字体、图标库、CDN——**文件必须自包含**，客户转发后不掉样式。

## 页面骨架

```
.wrap
├── nav.side      左侧 250px 粘性目录（01–11 + 编制信息）
└── main.main
    ├── section[role="cover"]  深色渐变封面：kicker / h1(含 em) / sub / .concl / .hstats×4
    └── section × 11
```

封面用 `role="cover"` 是为了转 Word 时能独立成页且不带页码；模板已用第二个 `<style>` 声明 `@page`（A4、页脚「页码 / 总页数」、右上页眉），**这份分页规则不影响屏幕观感**，也不要删掉。

打印时（`@media print`）侧边栏自动隐藏，其余保持。窄屏（<1100px）折叠为单列。

## 写作规则（与版式配套）

1. **标题即结论**：`h2.sec` 写"钱集中在哪一节"，不写"行业概况"。客户扫目录就能拿到判断。
2. **`.lead` 只放一段**：3–5 句讲完本节逻辑，中间用 `<strong>` 强调一句，全文渐变强调不超过 8 处。
3. **数字后必带标签**：`13 万台 <span class="tag l1">✅L1</span>`。无标签的数字等于没来源。
4. **表格优先于段落**：三类以上对比一律用表，`class="tight"` 用于 6 列以上。
5. **每家标杆结尾必须有 `.for`**：回答"对我们这个岗位意味着什么"，否则这段拆解对交付无价值。
6. **留白要显性**：不知道的写 `待核 <span class="tag l4">❓</span>`，并在第 10 节列出补法。不写看起来合理的假数据。

## 禁止项

- 不修改 `<style>` 中的任何令牌、字号、间距
- 不引入外部 CSS/JS/字体/图片（含 CDN）
- 不用浅色正文配浅色背景，不加动效与阴影特效
- 不把 `.callout` 当普通段落用（满屏彩色框等于没有重点）
- 不在报告正文写"我认为""我觉得"，改用"公告披露""研报测算""访谈显示"
- **不在页脚或附录披露资料来源清单**：不写"本报告资料来源包含…"。知识库名称**只允许**出现在标题为「延伸资源」的那一个链接区块里（页脚末尾 / docx 附录末尾 / xlsx 的「延伸资源」页），不进正文、不进第 11 节来源分级表、不以"资料来源"的名义列举。来源只用第 11 节的 L1–L4 等级与类型表达（官方公告 / 机构研报 / 行业媒体 / 待核验），客户只需知道每条数据的可信度，不需要知道我们读的是哪个库
- 不出现候选人真实姓名、电话、个人薪资（用 P1/P2 画像代号）

## 交付流程

1. 复制 `templates/report-template.html` → 改文件名为 `{行业}-{岗位}-行业速研与人才地图.html`
2. 替换 `{{}}`，删掉头部说明注释
3. 自检：`<style>` 未改、无外链、11 节齐全、每条数据带标签、页脚链接在
4. 转 docx：用 html-to-doc 转换，**必须传 `--require-page-furniture`**（模板已内置 `@page`，preflight 会校验；缺了会硬失败）。转换后**后置注入超链接**（`w:hyperlink` + 外部关系项），否则页脚链接点不动
5. 人才地图 xlsx 单独出，「延伸资源」页的链接要在
6. 对话回复末尾附知识库矩阵
