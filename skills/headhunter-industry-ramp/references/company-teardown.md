# 阶段 3 · 标杆企业拆解

## 选谁

**2 家老牌 + 2 家新锐。**

- 老牌提供人才存量（人多、体系成熟、可以挖）
- 新锐提供技术路线与人才增量（钱多、架构新、能挖到关键人）

**不要选 4 家同质的。** 选的时候刻意覆盖差异：不同技术路线、不同商业化阶段、不同客户群。四家长得一样，研究完你还是不知道行业分几派。

判断"谁值得研究"的土办法：看它的招聘页面。持续招人的公司在扩张，值得研究；半年没更新岗位的公司，可能已经在收缩。

## 五维拆解

### 1 产品
- 主营产品线有哪些，哪一个是拳头产品
- 在研产品、下一代路线
- 关键规格与价格带
- 目标客户是谁（B 端 / C 端 / 政府 / 科研）

### 2 技术
- 核心壁垒是什么（自研 vs 采购 vs 集成）
- 与竞品的具体差异（不是"更先进"，是"用什么换来什么"）
- 专利布局与数量
- 技术短板在哪（招股书风险因素里通常写着）

### 3 团队
- 创始人 / CEO / CTO 履历
- 核心研发骨干（技术总监、各方向负责人）
- 组织架构与人数变化趋势
- 关键人流失情况

### 4 商业化
- 是否量产，什么阶段
- 产能与良率
- 核心客户名单（具名还是"某客户"）
- 收入结构与毛利
- 订单/中标情况

### 5 最新动态（近半年）
- 融资、估值
- 新品发布
- 重大合作
- 高管变动、裁员、组织调整

## 组织切片（比五维更重要）

五维告诉你这家公司是什么样，组织切片告诉你**人怎么分布**——后者才是猎头要的。

切四层：
1. **分几个研发团队**？各管什么（算法 / 硬件 / 系统 / 测试 / 数据）
2. **每个团队多少人**？哪个团队最大（最大的那个就是公司当前重心）
3. **每个团队的负责人是谁**？什么背景，从哪来的
4. **汇报线怎么走**？谁向谁汇报，谁是真正的话事人

再加一条动态：近一年新增了哪些团队、流失了哪些关键人。新增的团队 = 新战略方向 = 新岗位机会；流失的关键人 = 已经可以打电话了。

## 商业化验证

**不看发布会，看这四项：**

| 看什么 | 有意义的信号 | 没意义的信号 |
|---|---|---|
| 交付/出货 | 第三方口径的台数、装机量 | "订单突破 X 亿"（意向也算订单） |
| 客户 | 具名客户 + 复购 | "某头部车企""多家世界 500 强" |
| 产能 | 产线数量、良率数字 | "规划产能 10 万台" |
| 收入 | 财报收入与毛利拆分 | 融资额、估值 |

翻译三句话：
- "即将量产" = 还没量产
- "小批量交付" = 有产品没规模
- "获得定点" = 有一单没放量

## 输出卡片格式

一页一公司，固定结构：

```
【公司名】成立年份 / 最新轮次 / 团队规模
产品：一句话说清它卖什么给谁
技术：一句话说清它和别人的区别（不是"技术领先"，是具体取舍）
团队：组织切片结论——几个组、谁带、重心在哪
商业化：交付验证结论——真交付还是讲故事
最新动态：近半年关键事件

—— 对我们的岗位意味着什么：
    1) 这是猎聘目标（我们要往这家送人）还是人才来源（我们从这家挖人）？
    2) 哪类人在这家公司最值钱？为什么？
    3) 我们能挖谁、挖不动谁，原因是什么？
```

**最后一段是灵魂。** 不写这段，等于只做了一份公司简介，对交付岗位零帮助。

## 四家卡片的横向对照

四张卡做完，横着看一遍，回答三个问题：

1. 四家的技术路线差异能不能用一张表说清？（能，说明你真的懂了）
2. 人才结构差异在哪？（谁家算法人多、谁家硬件人多）
3. 如果客户要的人只在其中一家有，那家就是唯一的池子——你的搜寻难度、议价空间都能算出来了
